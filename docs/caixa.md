# Caixa

Caixa de entrada do DM: uma linha por decisão ou ideia, com a data à frente, escrita onde calhar (telemóvel incluído). Não é cânone: o fecho seguinte converte cada linha numa decisão (`data/registo/decisoes/`, origem `voz`) ou numa pergunta (`data/registo/fios.json`) e esvazia esta lista.

<!-- Formato: `- AAAA-MM-DD — texto`. Exemplo: `- 2026-10-12 — o Morgid volta em Urzin com uma história nova`. -->
