# Referência de combate

Referência rápida para narrar combate físico: zonas do corpo, vocabulário por arma, escala de dano e reações. Consultar por secção. Vem do `combat_reference.md` da pasta `reference/` da Drive (2026-05-20), revisto para a skill `batalha` a 2026-10-20 (grafia de 1990, rótulos em português). Os exemplos são ponto de partida: adapta-os ao sítio, à criatura e ao equipamento, não os copies. A cópia-mãe está no repositório `dnd-skills`, em `skills/batalha/referencia-combate.md`.

## Zonas de impacto

| Zona | Efeito narrativo (golpe sólido) | Efeito mecânico sugerido |
| :-- | :-- | :-- |
| **Cabeça** | Desorientação, visão turva, queda | Stunned, prone |
| **Cara** | Sangue nos olhos, dor aguda, cicatriz | Blinded (temporário) |
| **Pescoço/garganta** | Engasgo, dificuldade em respirar ou falar | Não fala (sem componentes verbais), teste de concentração |
| **Ombro** | Braço dormente, a arma quase cai | Larga o que tem na mão (STR save) |
| **Tronco (frente)** | Ar expulso, costelas a estalar | Sem fôlego, deslocamento reduzido |
| **Tronco (lado)** | Dor a respirar, proteção instintiva | Desvantagem no próximo ataque |
| **Costas** | Arco involuntário, queda para a frente | Prone |
| **Braço da arma** | Mão enfraquecida, corte no antebraço | Perde a arma (STR save) |
| **Braço do escudo** | O escudo baixa, abre-se uma brecha | −2 CA (1 ronda) |
| **Mão/dedos** | A arma cai, grito de dor | Larga a arma |
| **Coxa** | Movimento comprometido, muito sangue | Deslocamento a metade |
| **Joelho** | Colapso parcial, instabilidade | Prone, deslocamento a metade |
| **Pé/tornozelo** | Desequilíbrio, coxeia | Deslocamento a metade |

> Os efeitos mecânicos são **sugestões** para críticos ou momentos narrativos, à escolha do DM. Não se aplicam a cada ataque e não são regra da casa.

## Armas corpo a corpo

### Espada longa (longsword)

- **Movimentos:** corte lateral, corte descendente, estocada, golpe com o pomo
- **Zonas:** tronco, pescoço, braços, pernas
- **Sons:** assobio no ar, estalo metálico contra armadura, som húmido contra carne
- **Verbos:** corta, rasga, crava, varre, decepa, talha, fende

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A lâmina passa rente ao peito; rasga o tecido e deixa uma linha vermelha fina, mas não entra.* |
| Sólido | *A espada apanha o flanco num arco lateral; corta o couro e a carne abre-se. Sangue imediato.* |
| Pesado | *Um corte descendente a duas mãos apanha o ombro e desce até ao peito. O corpo é empurrado para baixo com a força.* |
| Crítico | *A lâmina encontra a abertura entre o elmo e o gorjal e entra limpa no pescoço. Sangue arterial.* |
| Golpe final | *A espada atravessa o tronco e sai pelas costas. Os olhos arregalados. Os joelhos cedem.* |

### Espada curta (shortsword)

- **Movimentos:** estocada rápida, corte lateral curto, apunhalada, riposta
- **Zonas:** abdómen, axilas, flancos, garganta
- **Sons:** silvo curto, perfuração húmida, raspão metálico
- **Verbos:** apunhala, perfura, crava, espeta, retalha, pica

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A ponta raspa as costelas; não entra, mas a dor é aguda e imediata.* |
| Sólido | *Uma estocada rápida fura o abdómen. A lâmina entra um palmo e sai com um puxão.* |
| Pesado | *Cravada debaixo da axila, onde não há armadura; a lâmina afunda até ao punho.* |
| Crítico | *Encontra o espaço entre as placas e fura o rim. O corpo arqueia e um som gutural sai da garganta.* |

### Rapieira (rapier)

- **Movimentos:** estocada, finta, riposta, lançada, floreado
- **Zonas:** peito, garganta, cara, mão da arma
- **Sons:** silvo fino, tinido agudo contra metal, perfuração limpa
- **Verbos:** perfura, espeta, finta, trespassa, pica

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A ponta corta a bochecha: uma linha fina de sangue. Mais insulto do que ferida.* |
| Sólido | *Uma lançada rápida fura o ombro. A lâmina entra e sai num só movimento.* |
| Pesado | *A rapieira crava-se no peito com o peso do corpo todo por trás. A ponta sai pelas costas.* |
| Crítico | *Uma estocada precisa na garganta fura a traqueia. O sangue borbulha a cada tentativa de respirar.* |

### Montante (greatsword)

- **Movimentos:** arco largo, corte descendente, varrimento horizontal, estocada a meia-espada
- **Zonas:** tudo; a lâmina é enorme
- **Sons:** sopro grave no ar, estrondo contra armadura, som de talho
- **Verbos:** fende, decepa, parte, esmaga, varre

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A lâmina passa por cima; o vento do golpe bate na cara. Quase.* |
| Sólido | *Um arco horizontal apanha o tronco; a armadura amolga e o corpo é atirado dois passos para trás.* |
| Pesado | *O montante desce em arco entre o pescoço e o ombro. O corpo parte-se para baixo como lenha.* |
| Crítico | *Um corte a meia altura parte a armadura como casca de ovo. Uma só passagem da lâmina.* |

### Martelo de guerra (warhammer)

- **Movimentos:** golpe por cima, golpe lateral, de baixo para cima, pancada com o cabo
- **Zonas:** cabeça, ombros, joelhos, mãos
- **Sons:** sopro pesado, osso a estalar, badalada contra metal, baque surdo contra carne
- **Verbos:** esmaga, parte, estilhaça, esmigalha, amassa, martela

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O martelo passa rente ao ombro; sente-se o peso no ar e o braço fica dormente por reflexo.* |
| Sólido | *O martelo apanha o peito em cheio; a armadura amolga e o ar sai dos pulmões. Costelas a estalar.* |
| Pesado | *Um golpe por cima no topo do elmo. O pescoço encolhe, os joelhos cedem logo. O chão treme.* |
| Crítico | *O martelo apanha a rótula de lado; o joelho dobra ao contrário com um estalo que toda a gente ouve.* |

### Maça (mace)

- **Movimentos:** golpe lateral, por cima, de revés, toque com a ponta
- **Zonas:** cabeça, ombros, braços, costelas
- **Sons:** baque surdo, osso a estalar, tinido abafado contra armadura
- **Verbos:** esmaga, parte, amassa, afunda

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A maça raspa o braço; nódoa negra imediata debaixo da manga, dor a latejar.* |
| Sólido | *Apanha as costelas de lado; uma ou duas partem com um estalo audível. O corpo dobra-se para se proteger.* |
| Pesado | *Por cima, direta ao crânio. O elmo amolga, os olhos perdem o foco, o corpo cai como um saco.* |
| Crítico | *A maça apanha a têmpora com a rotação do corpo todo. O elmo voa. O que fica por baixo não é bonito.* |

### Machado (battleaxe)

- **Movimentos:** corte descendente, varrimento lateral, gancho (puxar com a barba do machado), golpe seco
- **Zonas:** pescoço, ombros, pernas, escudos
- **Sons:** sopro pesado, pancada em madeira ou osso, som de talho, escudo a rachar
- **Verbos:** decepa, racha, corta, crava, fende, arranca

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A lâmina apanha o braço de raspão; corte fundo mas curto. Sangue a escorrer pelo cotovelo.* |
| Sólido | *O machado crava-se no ombro, dois dedos de músculo. É preciso puxar para o soltar.* |
| Pesado | *Um golpe descendente parte a clavícula e afunda no peito. O braço desse lado cai sem força.* |
| Crítico | *O machado apanha o pescoço de lado. A cabeça não sai, mas fica num ângulo impossível.* |

### Adaga (dagger)

- **Movimentos:** apunhalada rápida, corte curto, arremesso, punhalada com a lâmina invertida
- **Zonas:** garganta, rins, axilas, olhos, tendões
- **Sons:** quase silenciosa; só o som húmido de entrar
- **Verbos:** apunhala, crava, espeta, rasga, corta, enterra

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A adaga corta a palma da mão que tentou travar: uma linha vermelha na diagonal.* |
| Sólido | *Cravada no flanco, entre as costelas. Rápida a entrar, rápida a sair. Sangue quente na mão.* |
| Pesado | *Enterrada até ao punho no rim, por trás. O corpo arqueia, a boca abre-se e não sai som nenhum.* |
| Crítico | *A adaga encontra a garganta num corte lateral rápido. Sangue arterial em arco.* |

### Bordão (quarterstaff)

- **Movimentos:** estocada, varrimento baixo, golpe por cima, bloqueio a rodar, estocada a duas mãos
- **Zonas:** cabeça, mãos, joelhos, costelas, pés
- **Sons:** pancada de madeira, estalo, sopro rápido
- **Verbos:** golpeia, varre, estala, bate, esmaga, empurra

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O bordão apanha os dedos; um estalo e a arma quase cai.* |
| Sólido | *Uma estocada direta ao plexo solar. O ar sai, o corpo dobra-se para a frente.* |
| Pesado | *Varrimento baixo nas pernas; os dois pés saem do chão. Queda dura de costas.* |
| Crítico | *Por cima, a duas mãos, direto ao topo do crânio. Um estalo. Os olhos reviram-se.* |

### Sem armas (unarmed)

- **Movimentos:** soco direto, de baixo para cima, gancho, cotovelada, joelhada, cabeçada, pontapé, agarrar
- **Zonas:** cara, abdómen, rins, garganta, virilha
- **Sons:** baque de carne, cartilagem a estalar, osso a partir, grunhido de esforço
- **Verbos:** esmurra, esmaga, agarra, projeta, torce, estrangula

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O soco apanha a orelha de raspão; zumbido imediato, um instante de tontura.* |
| Sólido | *Gancho no maxilar. A cabeça roda, saliva e sangue voam em arco. Os pés perdem o equilíbrio.* |
| Pesado | *Soco de baixo para cima no queixo, com o peso todo. Os dentes batem uns nos outros, a vista escurece.* |
| Crítico | *Soco direto no nariz; a cartilagem parte com um estalo molhado. Sangue de repente, em cascata.* |
| Agarrar | *O braço fecha-se à volta do pescoço, por trás; a pressão fecha a traqueia. O mundo começa a escurecer nas bordas.* |

## Armas à distância

### Arco longo (longbow)

- **Disparo:** *a corda vem até à orelha, dois dedos na corda, o arco geme com a tensão. Solta: um estalo seco.*
- **Voo:** *a flecha corta o ar com um assobio fino que cresce.*

| Golpe | Descrição |
| :-- | :-- |
| Falha | *A flecha crava-se na parede a dois dedos da cabeça e fica a vibrar. Demasiado perto.* |
| Raspão | *A flecha passa rente à cara; sente-se o vento antes de se ver a pena desaparecer atrás.* |
| Sólido | *A flecha enterra-se no ombro. A ponta sai pelas costas. O braço fica sem força.* |
| Pesado | *A flecha fura o peito e atravessa; a ponta sai pelas costas com carne e tecido.* |
| Crítico | *No olho. A flecha afunda até às penas. O corpo cai para trás sem um grito.* |

### Arco curto (shortbow)

- **Disparo:** *puxão rápido até ao queixo; menos tensão, mais velocidade. Estalo curto.*
- **Voo:** *mais curto, mais rasante. Menos assobio, mais direto.*

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *Corta o antebraço de passagem; como um corte de papel, mas fundo.* |
| Sólido | *Enterra-se na coxa. A perna cede no passo seguinte.* |
| Pesado | *Fura o pescoço de lado; a ponta sai do outro lado. Sangue em dois sítios.* |

### Besta (crossbow)

- **Disparo:** *o gatilho cede; um estalo metálico, mais violento do que um arco. O virote sai a direito, como uma linha.*
- **Voo:** *sem arco; trajetória plana, rápida, bruta.*

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O virote raspa a armadura e ressalta com um tinido metálico.* |
| Sólido | *O virote fura o couro e afunda no músculo. Não sai: fica preso.* |
| Pesado | *Atravessa a cota de malha como se não existisse e fica a tremer do outro lado.* |
| Crítico | *Direto ao esterno; o impacto empurra o corpo meio passo para trás antes de cair.* |

## Ataques naturais

### Garras

- **Movimentos:** golpe lateral, arranhão de cima para baixo, rasgar a puxar
- **Sons:** tecido e carne a rasgar, ar cortado
- **Verbos:** rasga, dilacera, arranca, marca, abre

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *Três linhas vermelhas paralelas no antebraço; pouco fundas, muito sangue.* |
| Sólido | *As garras rasgam o peito do ombro à anca; tecido e carne abrem em tiras.* |
| Pesado | *Arranhão de cima para baixo na cara. O elmo é arrancado e a cara por baixo abre em sulcos fundos.* |

### Mordida

- **Movimentos:** investida com a cabeça, dentada rápida, morder e não largar, sacudir para arrancar
- **Sons:** mandíbulas a fechar, osso a estalar, carne a rasgar, rosnido
- **Verbos:** morde, esmaga, arranca, tritura, cerra

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *As mandíbulas fecham-se a dois dedos do braço; o bafo quente e o estalar dos dentes.* |
| Sólido | *As mandíbulas fecham-se no antebraço; os dentes furam e a pressão esmaga o músculo contra o osso.* |
| Pesado | *Morde e não larga; os dentes afundam no ombro e a cabeça sacode de um lado para o outro. O corpo vai atrás como um boneco de trapos.* |
| Crítico | *As mandíbulas fecham-se na garganta. Pressão. Um estalo húmido. Silêncio.* |

### Cauda

- **Movimentos:** varrimento lateral, chicotada, pancada de cima para baixo
- **Sons:** sopro pesado, estalo de chicote, estrondo no chão
- **Verbos:** varre, chicoteia, esmaga, projeta, atira

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *A cauda passa por cima; o vento chega para desequilibrar.* |
| Sólido | *Varrimento lateral; o corpo sai do chão e voa três metros. Queda dura.* |
| Pesado | *A cauda apanha o tronco em cheio; as costelas partem em cadeia, como dominós. O corpo voa e bate na parede.* |

### Chifres (marrada)

- **Movimentos:** investida de cabeça baixa, estocada para cima, sacudidela da cabeça
- **Sons:** grunhido de esforço, estrondo do impacto, som de perfuração
- **Verbos:** empala, trespassa, projeta, esmaga, arranca

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O chifre raspa a armadura e deixa um sulco fundo no metal.* |
| Sólido | *O chifre fura o flanco, um palmo para dentro. A criatura sacode a cabeça e atira o corpo para o lado.* |
| Pesado | *Investida inteira; o chifre fura o peito e levanta o corpo do chão. Os pés a balançar no ar.* |

### Tentáculos

- **Movimentos:** chicotada, enrolar, apertar, pancada
- **Sons:** estalo húmido, som viscoso de sucção, ventosas a estalar
- **Verbos:** enrola, esmaga, puxa, chicoteia, agarra, arrasta, aperta

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O tentáculo chicoteia e deixa um vergão vermelho. Arde.* |
| Sólido | *Enrola-se no braço e aperta. As ventosas colam-se à pele. A pressão cresce.* |
| Pesado | *Enrola-se no tronco e aperta; o ar sai, as costelas vergam. A vista escurece nas bordas.* |
| Agarrar | *Vários tentáculos enrolam o corpo ao mesmo tempo, cada um a apertar para um lado. O corpo é puxado para a boca.* |

### Pancada (slam)

- **Movimentos:** pancada por cima, de revés, encontrão, murro no chão
- **Sons:** estrondo do impacto, pedra ou terra a rachar, esmagamento
- **Verbos:** esmaga, atira, projeta, amassa, afunda

| Golpe | Descrição |
| :-- | :-- |
| Raspão | *O punho enorme passa ao lado; o chão onde bate racha.* |
| Sólido | *De revés, no tronco; o corpo voa como uma bola de trapos e cai a cinco metros.* |
| Pesado | *Pancada por cima com os dois punhos. O chão abre uma cratera. O corpo afunda na terra.* |

## Escala de dano narrativo

Calibra a descrição pelo dano que saiu no dado:

| Dano | Golpe | Tom | Exemplo |
| :-- | :-- | :-- | :-- |
| 1–3 | Raspão | Quase falhou | *Raspa, marca à superfície, corte de nada. Dói, mas não impede.* |
| 4–7 | Sólido | Acertou bem | *Sangue, dor a sério, impacto visível. O corpo acusa.* |
| 8–12 | Pesado | Golpe devastador | *Osso a estalar, grito sem querer, queda. Dano sério.* |
| 13–18 | Brutal | Quase mortal | *Desfiguração, perda de função, muito sangue. Choque.* |
| 19+ | Catastrófico | Massacre | *Membros, destruição, horror. Só criaturas com muitos PV aguentam isto.* |
| Crítico | Perfeito | O melhor golpe possível | *O golpe impossível: a falha na armadura, o ângulo certo, o momento exato.* |

## Reações ao dano

Como descrever quem **recebe** o golpe, pelos PV que lhe restam:

| PV restantes | Variante | Comportamento |
| :-- | :-- | :-- |
| 75–100% | magoa | *Acusa o golpe, cerra os dentes, ajusta a guarda. Ainda forte.* |
| 50–75% | magoa | *Respiração pesada, sangue à vista, a guarda a baixar. Começa a proteger o lado ferido.* |
| 25–50% | fere | *Coxeia, um olho fechado, braço pendurado. O desespero começa a aparecer nos olhos.* |
| 1–25% | fere | *Mal se aguenta de pé. Cada respiração é um gemido. Sangue por todo o lado. Agarrado à vida.* |
| 0 (inconsciente) | final | *Os olhos reviram-se. Os joelhos cedem. O corpo cai como se lhe cortassem os fios.* |
| 0 (morto) | final | *Depende do golpe final: ver a arma.* |

## O sítio reage

| Elemento | O que acontece |
| :-- | :-- |
| **Chão de terra** | *Sangue absorvido, lama, pegadas de luta* |
| **Chão de pedra** | *Poças de sangue, faíscas de metal, ecos que crescem* |
| **Madeira e mobília** | *Estilhaça com o impacto, mesas viradas, cadeiras partidas* |
| **Paredes** | *Flechas cravadas, marcas de lâmina, sangue espirrado* |
| **Vegetação** | *Ramos cortados caem, folhas no ar, troncos marcados* |
| **Água e lama** | *Salpicos no impacto, sangue a diluir-se, escorregadelas* |
| **Fogo e tochas** | *Derrubados, óleo espalhado, risco de incêndio* |
| **Os outros** | *Param para ver, saem do caminho, gritam avisos* |

## Notas de uso

- **Em combate,** lê só a linha que interessa; não narres tudo.
- **Varia a zona,** para não repetir onde os golpes acertam.
- **Escala com o contexto:** um goblin a atacar não é um dragão a atacar (mesmo dano, tom diferente).
- **Falhar é narrativo:** uma falha descreve o que **quase** aconteceu.
- **PCs e NPCs recebem dano de maneira diferente:** os PCs são heróis; o dano marca, mas não os incapacita antes de 0 PV.
